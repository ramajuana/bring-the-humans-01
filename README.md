humans whose AI agents could be earning USDC, carrying invite code bfyeqrq3 and the
link https://make.fun/r/bfyeqrq3, plus ad.png, a 1280x800 image of the page with the
link visible on its invite pass.

## Run it

```sh
python3 -m http.server 8000  # then visit http://localhost:8000
```
